Git-native

Every change is a commit you can read

Files are plain JSON in your repo. The change list names layers, not lines. Visual diffs, pull requests with comments pinned to layers, and a merge that resolves property by property. Works with GitHub, GitLab, Bitbucket, Gitea or any git URL.

Private assistant

An assistant that never leaves your Mac

Connect LM Studio, Ollama, llama.cpp or any OpenAI-compatible server. The assistant sees your selection, proposes edits, and every applied edit lands in the change log so you can review or undo it. Cloud models are optional and can be blocked per project.

Built in the open. Shaped by the people who use it.

Found a bug or missing a feature? Report it from inside the app with one click, or on GitHub. Every issue is public, labeled and answered.

Boilerplate

Draften is a free, open-source design tool for macOS created by Ankur Sinha. Designs are stored as plain files in a git repository, so teams branch, commit, review and merge design work the same way they ship code. Draften includes live co-editing, interactive prototypes, and an assistant that runs on local models through LM Studio, Ollama or llama.cpp. It is released under the MIT license.
