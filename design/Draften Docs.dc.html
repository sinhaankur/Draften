The idea

Draften is a local-first macOS design tool where every board, component and token is a plain, diffable file inside a git repository. Designers branch, commit, review and merge the way engineers do, and work together live on the same branch. A built-in assistant runs on a local model through LM Studio, Ollama, llama.cpp or any OpenAI-compatible server, and edits the file through the same change log a person uses.

ProblemDesign files live outside the repo. Versions drift from shipped code, reviews happen on screenshots, and nobody can say which design matches a release.
Who it is forProduct designers on teams that ship from git, design-system maintainers who version tokens with code, and solo designers who want history without a subscription.
OutcomeA design change is a commit. A design review is a pull request with visual diffs. A design-system release is a tag that code can depend on.
