Documentation

Draften, start to finish.

A free, open-source design tool whose files live in your git repo, with an on-device AI companion. This page takes you from install → connected → designing → committed.

New here? The fastest path: open the web app and start drawing. When you're ready to save, connect a GitHub token (below) and commit.

Install, or open in the browser

Draften runs everywhere. Pick whichever fits:

  • Web app — open it now, nothing to install, any device.
  • Desktop — download for macOS, Windows, or Linux (every chip). The desktop app adds offline persistence and native file dialogs.
Free forever. There is no paid tier. The desktop builds and the web app are the same app — use what you like.

The user flow

The whole journey, at a glance. Each step is detailed below.

Open Draften

Install a build or open the web app. You can start designing immediately — no sign-up wall.

Connect a GitHub token

Create a free personal access token with repo scope and paste it once. That token is your account — no separate Draften login.

Design

Add artboards, draw layers, use the inspector, ask the AI companion to generate screens. It's a real canvas.

Commit to your repo

Save your design as open-format files and commit / branch / open a PR — your design history is git history.

Why git is your account

Most design tools make you create an account and store your files on their cloud — which is what you end up paying for. Draften flips that: your designs are plain files, and your “account” is your git login. That means:

  • No new password to manage — you already have a GitHub account.
  • No cloud bill — your files live in your repository.
  • Real version control — branches, diffs, PRs, history, for free.
  • Your team already knows the workflow.

GitHub is supported today. GitLab, Bitbucket, and any-git are on the roadmap — the provider is intentionally kept swappable.

Create a GitHub token (free)

A personal access token lets Draften read and write your design repo on your behalf. It takes a minute:

  1. Go to github.com/settings/tokens/new (you may need to sign in to GitHub).
  2. Give it a name like Draften.
  3. Under scopes, tick repo — this is the only scope Draften needs (read/write your repositories).
  4. Click Generate token and copy it. GitHub shows it only once.
What scope do I pick? Just repo. Draften never needs admin, delete, or org scopes. If you only want a single repo, use a fine-grained token scoped to that repo with Contents: Read and write.

Connect it in Draften

  1. In Draften, click the account avatar at the bottom of the left icon rail.
  2. Choose “Connect with a GitHub token.”
  3. Paste your token and press Connect.

You're now signed in — the menu shows your name and avatar, and the Source control panel (Clone / Pull / Commit / PR) unlocks.

Paste not working? Click into the token field first, then paste (⌘V / Ctrl-V). The field reads the clipboard directly, so your token won't be swallowed by the canvas paste handler. If you reinstalled, reconnect once.

Design → commit to your repo

Your design is saved as open-format files, so git handles them like any source:

  1. Open the Source control panel (the git icon in the left rail).
  2. Clone a repository (or point at one you've already cloned).
  3. Design. When ready, write a message and Commit.
  4. Push, branch, or open a PR — exactly like code.

Design on the canvas

Draften is a real design surface, not a wireframe toy:

  • Artboards — add iPhone / Android / tablet / desktop / square frames from the + in the Artboards section.
  • Layers — a nested tree with rename, lock, show/hide, reorder, duplicate, and group.
  • Inspector (right panel) — Position, Size, Opacity, Fill, Stroke, Effects, Text. Edit any value precisely.
  • Boolean shapes — select two shapes → Union / Subtract / Intersect / Difference → a real editable vector path.
  • Align & distribute — appears when 2+ layers are selected.
  • Styles & tokens — shared color & text styles, your design system versioned with the file.

The AI companion

Open the Assistant tab (the ✦ panel). It's a real conversation that draws onto your canvas:

  • Describe a screen — “a fitness app home with a weekly streak and a start button” → real, editable layers.
  • Keyless automations — “table of contents for: Intro, Setup, API” or “a 3×2 card grid”, “a nav bar”, “a flowchart”. These run instantly, offline, with no model at all.
  • Bring a model — point at a local LM Studio / Ollama model, or use Apple Intelligence on macOS, for free-form conversation. No API keys, no per-use bills.

Open Sketch / Figma / OmniGraffle / PDF

It's your file — Draften opens it, rather than locking you out. Use Import file (in the left panel) or drag a file onto the canvas.

  • Sketch (.sketch) — a zip of JSON; imported as real editable artboards & layers.
  • OmniGraffle (.graffle) — the gzipped Apple binary property list is decoded in-app (no plugin) → shapes, connectors, groups and text become editable layers.
  • Figma — a .fig is proprietary binary, so Draften opens your file via Figma's official REST API: paste the file URL and a Figma personal access token, and the document imports as frames, shapes and text. (Your token, your file — nothing leaves your machine except the call to Figma.)
  • PDF — opens as an editable page: text becomes editable text layers over a page sheet.
  • Word (.docx) — text extracted to layers.
Unknown pieces aren't dropped. If a file uses a feature Draften doesn't fully map yet, it's approximated to the closest shape and noted in the import warnings — so you never lose content. The on-device AI can help refine ambiguous imports.

Get a Figma token

  1. In Figma: Settings → Security → Personal access tokens → Generate new token (read-only file access is enough).
  2. Copy the token.
  3. In Draften: Import file → Figma, paste the file URL and the token, and import.

Combine shapes (boolean)

Select two or more shapes, then use the Combine bar in the inspector:

  • Union — merge into one shape.
  • Subtract — cut the later shapes out of the first.
  • Intersect — keep only the overlapping area.
  • Difference — keep everything except the overlap.

The result is a real, editable vector path — keep nudging its points. Great for icons and custom silhouettes.

Layer actions

In the Layers panel, each layer supports the Sketch/Figma essentials:

  • Rename — double-click the name (or right-click → Rename).
  • Lock / unlock and show / hide — the icons on the right of each row.
  • Reorder — drag a layer up or down to change its z-order.
  • Right-click for: Duplicate, Lock, Bring to front, Send to back, Delete.
  • Wrap in artboard — select loose layers → Wrap to put them in a new frame.

Prototype & play

  1. Open the Prototype tab.
  2. Select a layer, choose Navigate to… a frame, pick an animation (smart-animate / dissolve / push / slide) and duration, then Link.
  3. Hit Play — click through your screens in the browser.

Export

  • Images — export layers / artboards as PNG / SVG / PDF at 1×/2×/3×.
  • Runnable app — File → Build app exports a full Vite + React + TypeScript project (or standalone HTML). Your design becomes code you can run.
  • Open format — File → Save writes a diff-able design file you commit to git.

MCP & the SKILL file

Draften is an MCP server: an AI client (like Claude Desktop) can read and edit your design through named tools — get_design, export_html, add_rectangle, add_text. Open the MCP panel to copy the client config.

A SKILL.md ships in the repo — it teaches any model (Claude, your on-device model, an MCP client) how to drive Draften well: its primitives, the keyless automations, and the right way to generate a design. It's the modern version of OmniGraffle's scripting, for the AI era.

Privacy & offline

  • Local-first — your files are yours; nothing is uploaded to a Draften server (there isn't one).
  • Offline — the desktop app and keyless automations work with no network.
  • Your git, your data — the only cloud involved is the git host you choose.
  • On-device AI — model inference runs on your machine; prompts don't leave it.

Troubleshooting

“I can't paste my token”

Click into the token field first, then paste. If you just reinstalled, reconnect once.

“Sign-in says ‘Load failed’”

Use the token path (not the browser device-flow) — the webview blocks the GitHub device-flow request for security reasons. The token flow always works.

“Dragged a PDF and nothing happened” (desktop)

This is fixed in current builds. If you're on an old one, update from Download.

Something else?

Open an issue on GitHub — it's open source, and every report helps.
